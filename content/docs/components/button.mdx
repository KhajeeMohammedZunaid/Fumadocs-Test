# Button

A versatile button component built on top of `@base-ui/react/button` with `cva` variants.

## Preview

<div className="flex flex-wrap items-center gap-3 p-6 border rounded-xl not-prose my-4">
  <Button variant="default">Default</Button>
  <Button variant="secondary">Secondary</Button>
  <Button variant="outline">Outline</Button>
  <Button variant="ghost">Ghost</Button>
  <Button variant="destructive">Destructive</Button>
</div>

## Usage

```tsx
import { Button } from "@/components/ui/button";

export default function Example() {
  return <Button variant="default">Click me</Button>;
}
```

## Variants

| Variant | Description |
| --- | --- |
| `default` | Primary solid button |
| `secondary` | Muted background with high contrast text |
| `outline` | Bordered button with hover background |
| `ghost` | Transparent background with hover effect |
| `destructive` | Destructive danger button |
| `link` | Underlined text button |

## Sizes

| Size | Height |
| --- | --- |
| `xs` | Extra small button |
| `sm` | Small compact button |
| `default` | Standard button height |
| `lg` | Large prominent button |
| `icon` | Square icon-only button |
