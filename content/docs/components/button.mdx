## Basic Usage

Import and use `StuxButton` with any variant, pattern, or color scheme:

```tsx
import { StuxButton } from "@/components/stux-button";

export default function Example() {
  return (
    <StuxButton variant="edge-fill" fillPattern="wave" colorScheme="yellow">
      LET'S TALK
    </StuxButton>
  );
}
```

## Props Specification

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `"default" \| "edge-fill"` | `"default"` | Determines the interaction mode. `"default"` triggers the split-arrow pass-through animation, while `"edge-fill"` sweeps a seamless SVG contour fill from left to right. |
| `fillPattern` | `"cross" \| "wave" \| "cyber" \| "arc" \| "zigzag"` | `"cross"` | The leading SVG shape contour used when `variant="edge-fill"`. |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Controls the button's proportional height, endcap width, font size, padding, and arrow distance. |
| `colorScheme` | `"yellow" \| "lime" \| "cyan" \| "orange" \| "white" \| "violet" \| "emerald"` | `"yellow"` | Built-in high-contrast brutalist color scheme preset. |
| `text` | `string` | — | Button label text. Overrides default variant fallback text. |
| `customAccent` | `string` | — | Custom hex or CSS color string to override the accent fill color. |
| `menuOpen` | `boolean` | `false` | When true, forces the active expanded state (useful for menu triggers or active navigation). |
| `onClick` | `(e: React.MouseEvent) => void` | — | Click event callback. |
| `className` | `string` | — | Additional CSS utility classes. |
| `children` | `React.ReactNode` | — | React children rendered as button content. |
