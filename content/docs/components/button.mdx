## Variants

| Variant | Description |
| :--- | :--- |
| `default` | Primary solid button for main call-to-actions |
| `secondary` | Subtle high-contrast button for secondary actions |
| `outline` | Bordered button with hover background |
| `ghost` | Borderless button with gentle hover background |
| `destructive` | High-visibility danger button for destructive operations |
| `link` | Underlined link-style button |
