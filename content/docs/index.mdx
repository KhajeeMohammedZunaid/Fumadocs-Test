# UI Component Library

Welcome to the component library documentation. This site is built with **Fumadocs**, **Next.js 16 (App Router)**, **Base UI**, and **Tailwind CSS v4**.

## Architecture & Tech Stack

- **Framework**: [Next.js](https://nextjs.org) with App Router & Turbopack
- **Documentation**: [Fumadocs](https://fumadocs.dev) (`fumadocs-ui`, `fumadocs-core`, `fumadocs-mdx`)
- **Typography**: [Inter](https://fonts.google.com/specimen/Inter) via `next/font/google`
- **Primitives**: Accessible headless components via `@base-ui/react`
- **Styling**: Tailwind CSS v4 with custom shadcn-aligned theme tokens
